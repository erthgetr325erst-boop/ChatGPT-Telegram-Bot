# 🤖 Telegram ChatGPT Bot

A feature-rich Telegram bot that provides an AI-powered conversational experience through Telegram.

## ✨ Features

* 💬 **AI Conversations:** Chat with AI directly through Telegram.
* 🗂️ **Multiple Conversations:** Create and manage multiple conversations.
* 🧠 **Model Selection:** Choose from the available AI models.
* 💾 **Conversation History:** Save conversations using SQLite.
* ⚡ **Streaming Responses:** Receive responses progressively.
* 📝 **Saved Prompts:** Save frequently used prompts for quick access.
* 🔐 **Channel Subscription:** Require users to join a specific Telegram channel.
* 📊 **Statistics:** View bot usage statistics.
* 🎛️ **Interactive Interface:** Easy-to-use buttons and menus.

## 🛠️ Technologies Used

* Python 3
* pyTelegramBotAPI
* SQLite
* Requests
* Telegram Bot API

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Open the project folder

```bash
cd YOUR_REPOSITORY
```

### 3. Install dependencies

```bash
pip install pyTelegramBotAPI requests
```

### 4. Configure the bot

Add your Telegram Bot Token to the configuration.

**Important:** Never publish your bot token, session cookies, API keys, or other private credentials.

### 5. Run the bot

```bash
python chatgpt.py
```
